# NETWORKWALKS-AMINADUZE-B084-WK1-PM1-CYBERSECURITY-LAB-SETUP
Hands-on cybersecurity lab setup using VMware Workstation and Kali Linux, featuring NAT networking, static IP configuration, shared folders and connectivity testing.
This project involved setting up a virtual cybersecurity testing laboratory using VMware Workstation and Kali Linux. The objective was to establish an isolated virtual environment for practising ethical hacking, network security testing, and other cybersecurity exercises.
